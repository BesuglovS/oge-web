## 📋 Найденные проблемы

### 🔴 Критические проблемы

#### 1. Встроенный CSS во всех файлах
- **Проблема:** Каждый HTML содержит значительный объём CSS в `<style>` (например, `oge1.html` — 926 строк всего, из которых бóльшая часть — CSS). CSS практически идентичен во всех файлах (30+ HTML-файлов).
- **Влияние:**
  - Дублирование CSS кода в каждом файле (30+ × ~400-500 строк CSS = ~13 000 строк дубликата)
  - Файлы становятся большими
  - Сложно поддерживать общие стили
- **Решение:** Вынести CSS в общий `assets/styles.css`

#### 2. Дублирование теоретических страниц
- **Проблема:** Каждый файл имеет отдельную теорию (`oge{N}-t.html`)
- **Влияние:**
  - Теория повторяется в каждом файле
  - Нет общей базы знаний
  - Сложно обновлять теорию
- **Решение:** 
  - Общая база теории в `docs/theory.json`
  - Ссылки на общую теорию из заданий

#### 3. Неполная SEO-оптимизация
- **Проблема:** `<title>` есть в каждом файле (напр., «Задание 1 ОГЭ - Информационный объём»), но `<meta name="description">` и `<link rel="canonical">` отсутствуют
- **Влияние:** Поисковые системы не видят описания страниц, снижается CTR в выдаче
- **Решение:** Добавить `<meta name="description">` и `<link rel="canonical">` в каждый файл

#### 4. Нет сохранения прогресса
- **Проблема:** Результаты тестов не сохраняются
- **Влияние:** Потеря прогресса при перезагрузке
- **Решение:** localStorage для сохранения результатов

#### 5. JS inline в HTML
- **Проблема:** JavaScript код в `<script>` внутри HTML
- **Влияние:** Сложно тестировать, нельзя реюзить компоненты
- **Решение:** Вынести JS в `js/trainer-{task}.js`

#### 6. Неполный охват интерактивом
- **Проблема:** Задания 13.1, 13.2 и 14 не имеют интерактивных страниц — только теория
- **Влияние:** Неравномерное покрытие, пользователи не могут попрактиковаться
- **Решение:** Разработать интерактивные версии для всех заданий

#### 7. Нет системы подсчёта результатов
- **Проблема:** Результаты не аккумулируются
- **Влияние:** Нет статистики успеваемости
- **Решение:** Система баллов и уровней

### 🟡 Важные улучшения

#### 8. Навигация между заданиями (prev/next)
- **Проблема:** Переходы «задание ↔ теория» и «← На главную ОГЭ» уже есть (34 элемента навигации). Но отсутствует линейная навигация «Предыдущее задание / Следующее задание» (напр., из Задания 4 нельзя перейти сразу в Задание 5 без возврата на главную)
- **Влияние:** Пользователь вынужден каждый раз возвращаться на индексную страницу
- **Решение:** Добавить prev/next-кнопки между последовательными заданиями

#### 9. Доступность (a11y)
- **Проблема:** Нет ARIA-атрибутов, focus indicators
- **Влияние:** Проблемы для screen readers
- **Решение:** ARIA labels, focus styles

#### 10. PWA / Офлайн
- **Проблема:** Нет manifest, sw.js
- **Влияние:** Нет офлайн-доступа
- **Решение:** PWA манифест, service worker

#### 11. Локализация
- **Проблема:** Только русский язык
- **Влияние:** Нет доступа для иностранных пользователей
- **Решение:** Добавить английский перевод

#### 12. Аналитика событий
- **Проблема:** Yandex Metrika есть, но нет event tracking
- **Влияние:** Неизвестно какие задания популярны
- **Решение:** event tracking для всех действий

#### 13. Визуальные улучшения
- **Проблема:** Иконки заданий используют emoji (🌐, 📚, 🎮), что функционально, но стилистически неединообразно
- **Решение:** SVG иконки с единым стилем и SVG-фильтрами

### 🟢 Дополнительные улучшения

#### 14. Система уровней
- **Проблема:** Нет уровней/достижений
- **Решение:** 
  - Система уровней (Новичок → Мастер)
  - Достижения за задания
  - Сертификаты

#### 15. Лидерборд
- **Проблема:** Нет рейтинга
- **Решение:** 
  - Leaderboard по результатам
  - Возможность делиться результатами

#### 16. Тестовые данные
- **Проблема:** `oge7.txt` - hardcoded данные
- **Решение:** JSON конфиг задач

#### 17. Unit-тесты
- **Проблема:** Нет тестов для проверки
- **Решение:** Vitest для интерактивных функций

### localStorage для прогресса

```javascript
// js/save-progress.js
const STORAGE_KEY = 'oge-progression';

export function saveResult(taskId, score) {
  const progress = JSON.parse(localStorage.getItem(STORAGE_KEY) || '{}');
  progress[taskId] = {
    score,
    attempts: (progress[taskId]?.attempts || 0) + 1,
    lastAttempt: new Date().toISOString()
  };
  localStorage.setItem(STORAGE_KEY, JSON.stringify(progress));
}

export function getProgress() {
  return JSON.parse(localStorage.getItem(STORAGE_KEY) || '{}');
}
```

# Архитектура проекта oge-web

## Обзор

Статическое веб-приложение для подготовки к ОГЭ по информатике. Содержит 16 типов интерактивных заданий с drag-and-drop, автоматической проверкой и серверной песочницей для задания 16 (программирование на Python).

## Структура проекта

```
oge-web/
├── oge.html                   # Главная (выбор заданий)
├── oge1.html  — oge16.html    # Интерактивные задания (16 шт.)
├── oge1-t.html — oge16-t.html # Теоретические страницы
├── oge4-path.html             # Альтернативный вариант задания 4
├── run_python.php             # Серверная песочница (Python)
├── files/                     # Статические данные
│   ├── oge15/                 # Данные для задания 15
│   └── *.zip                  # Архивы для заданий 11–12
├── p/                         # Дополнительные ресурсы
├── git/                       # Git-ассеты
├── .htaccess                  # Конфигурация Apache
├── LICENSE                    # MIT
└── README.md
```

## Архитектура приложения

### Клиентская архитектура

Каждое задание — самостоятельный HTML-файл с inline CSS и embedded JavaScript:

```
oge.html (навигация)
├── oge1.html  (Информационный объём)
├── oge2.html  (Декодирование сообщений)
├── oge3.html  (Истинность высказывания)
├── oge4.html  (Анализ модели объектов)
├── oge5.html  (Анализ алгоритмов)
├── oge6.html  (Анализ программы)
├── oge7.html  (Составление URL)
├── oge8.html  (Множества и круги Эйлера)
├── oge9.html  (Задание 9)
├── oge10.html (Системы счисления)
├── oge11.html (Поиск информации)
├── oge12.html (Файловая система)
├── oge13.html (Презентации)
├── oge14.html (Электронные таблицы)
├── oge15.html (Алгоритмы Робот/Кумир)
└── oge16.html (Программирование на Python) ← песочница
```

### Типы интерактива

| Технология | Задания |
|------------|---------|
| Drag-and-drop API | oge2, oge4, oge7, oge8 |
| Touch events | Все drag-and-drop задания |
| Ввод текста | oge1, oge3, oge6, oge10 |
| Выбор ответа | oge5, oge9, oge15 |
| Серверный запуск | oge16 (Python) |

### Серверная песочница (run_python.php)

Задание 16 выполняет Python-код на сервере:

```
HTTP POST (code, test_input, expected_output)
    │
    ▼
run_python.php
    ├── Валидация входных данных
    ├── Проверка белого списка модулей
    │   (math, random, datetime, re, json, csv, ...)
    ├── Блокировка опасных паттернов
    │   (exec, eval, open, __import__, os, subprocess, ...)
    ├── Ограничение размера кода (20 КБ)
    ├── Запуск через shell_exec с timeout 5
    └── JSON-ответ {output, expected, match, error}
```

### Белый список модулей

Разрешены: `math`, `random`, `datetime`, `re`, `json`, `csv`, `itertools`, `functools`, `collections`, `string`, `decimal`, `fractions`, `statistics`

Запрещены: `os`, `sys`, `subprocess`, `shutil`, `ctypes`, `socket`, `http`, `urllib`, `pathlib` (через `__import__`)

### Хранение данных

Данные заданий захардкожены в JavaScript каждого HTML-файла. Прогресс сохраняется в `localStorage`.

| Ключ | Назначение |
|------|-----------|
| `oge-progress` | Пройденные задания |
| `oge-theme` | Предпочтения темы |

## Дизайн-система

Общая с экосистемой:

- Фон: тёмный градиент
- Карточки: полупрозрачные с градиентными бордерами
- Нумерация заданий: цветные бейджи с градиентами
- Анимации: hover-эффекты, плавные переходы
